# User Guide: From first launch to full app usage

This guide explains the current end-to-end flow for the app so new users can get started without confusion.

> Note: the current build uses a demo identity field instead of a full sign-up form. In practice, this means choosing a user ID is the first onboarding step before generating content or managing billing.

## 1. Open the app

- Open the app in your browser.
- You will land on the prompt studio home screen.
- The screen is divided into a few clear areas:
  - Prompt studio for creating content
  - Recent generations for reviewing past work
  - Studio dashboard for plan and quota details
  - Billing section for plan changes and payments

## 2. Create your user identity

- In the Demo identity field, enter any user ID you want to use, such as `alex` or `creator-1`.
- This ID is used to associate your draft, history, and billing state with your session.
- The app saves this locally in the browser so your work can be restored when you return.

## 3. Understand the main tools

### Prompt studio
Use this area to:
- Enter a short story or plot idea
- Click Generate prompts
- Review the generated scene prompts
- Preview the generated prompt visuals

### Recent generations
Use this area to:
- Review previously created prompt packs
- See examples of earlier story-to-scene outputs
- Revisit past work without recreating it from scratch

### Studio dashboard
Use this area to:
- Check your current identity
- See your current plan
- Check remaining request quota

### Billing page
Use the billing page to:
- Choose a plan
- Start checkout for a paid subscription
- Open the customer portal for account billing actions

## 4. Generate your first prompt pack

1. In the story box, enter a short but clear idea.
2. Make it specific by including mood, setting, or conflict.
3. Example: “A lonely astronaut finds a hidden garden beneath a frozen moon.”
4. Click Generate prompts.
5. Wait for the app to create your prompt sequence.

### Good prompt-writing tips
- Keep the story short and focused.
- Mention one clear mood or visual direction.
- Avoid vague input such as “a cool story” without context.

## 5. Review the generated results

- The app will show a list of generated scenes.
- Each result includes a preview image and a descriptive scene prompt.
- Review the outputs before using them in a project, portfolio, or client workflow.

## 6. Use history and resume work

- If you return later, the app can restore your last draft and recent results.
- Your history is displayed on the home page for quick access.
- If history looks empty, make sure you are using the same identity that created the earlier output.

## 7. Manage billing and plan access

1. Open the billing page.
2. Enter or confirm your user ID.
3. Review the available plans.
4. Choose a plan that matches your needs.
5. Click the checkout or portal option to continue.

### What each plan is for
- Pro: good for creators who want reliable prompt generation
- Studio: good for more advanced scene refinement and higher usage
- Business: good for team or agency-style workflows

## 8. Resolve common issues

### If generation fails
- Make the story clearer and more specific.
- Keep the content within the app’s allowed use cases.
- Try again with a shorter prompt.

### If you are out of requests
- Wait for the next reset window or upgrade your plan.
- Review the remaining request count in the dashboard.

### If history is missing
- Use the same identity as before.
- Generate a new prompt first if the history panel is empty.

### If something feels wrong
- Read the support message shown by the app.
- Simplify the input and try again.
- Check whether your use follows the displayed restrictions.

## 9. Best practices for smooth use

- Start with one clear idea instead of a long, loosely structured paragraph.
- Keep prompts intentional and focused.
- Review outputs for quality, tone, and legal compliance.
- Use the billing page whenever you want to upgrade or review plan limits.
- Reuse the same identity if you want your history and quota state to remain consistent.

## 10. Quick start checklist

- Open the app
- Enter a user ID
- Write a short story idea
- Generate prompts
- Review the results
- Visit the billing page if you need more quota or plan changes

If you follow these steps, you should be able to move from first launch to full use of the app with minimal friction.
